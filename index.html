Perguntas frequentes

Preciso de uma loja online?

Não. Crie um link de pagamento e partilhe onde quiser (WhatsApp, redes, email).

Como funciona o pagamento manual?

O sistema gera uma referência única. O cliente transfere para o seu número M-Pesa/eMola ou conta bancária. Você confirma no painel quando receber o comprovativo.

É seguro?

Sim. O site é estático + localStorage no seu browser. Não armazenamos dados sensíveis em servidores externos. Você controla os números de pagamento.

Posso integrar com o meu site?

Sim. Veja a documentação da API (docs.html) e use os endpoints mock ou ligue o seu backend.

Pronto para receber do seu jeito?
